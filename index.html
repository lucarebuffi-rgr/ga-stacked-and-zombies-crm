⚙️ One-time setup needed

  1. In Google Drive, set both lead sheets to Anyone with the link → Viewer (GA ZOMBIE LEADS and GA STACKED LEADS).
  2. Create a Google Cloud API key with the Google Sheets API enabled (restrict the key to the Sheets API), then paste it into CONFIG.SHEETS_API_KEY at the top of this file's script. For property photo thumbnails, also enable the Google Drive API on the same key and share each property's Drive folder as "Anyone with the link".
  3. Republish the site. Sheets are read live and read-only — statuses, notes, calls, tasks and family trees are stored separately in Firestore.
